Paso 2: Crear Tablas en Supabase

Ejecuta este SQL en el SQL Editor de tu proyecto Supabase:

-- Crear tabla plans CREATE TABLE public.plans ( id TEXT PRIMARY KEY, name TEXT NOT NULL, owner TEXT, description TEXT, created_at DATE, updated_at TIMESTAMP DEFAULT NOW() ); -- Crear tabla initiatives CREATE TABLE public.initiatives ( id TEXT PRIMARY KEY, plan_id TEXT NOT NULL REFERENCES public.plans(id) ON DELETE CASCADE, name TEXT NOT NULL, responsible TEXT, start_date DATE, end_date DATE, priority TEXT DEFAULT 'medium', status TEXT DEFAULT 'not-started', progress INTEGER DEFAULT 0, phases TEXT[], updated_at TIMESTAMP DEFAULT NOW() ); -- Desactivar RLS (para usar sin autenticación) ALTER TABLE public.plans DISABLE ROW LEVEL SECURITY; ALTER TABLE public.initiatives DISABLE ROW LEVEL SECURITY; -- Crear índices CREATE INDEX idx_initiatives_plan_id ON public.initiatives(plan_id);
⚠️ Importante: Si planeas usar autenticación después, mantén RLS activado y configura policies.
